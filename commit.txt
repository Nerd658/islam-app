2026-08-07 — PWA Manifest Updates & Quran Karaoke UX Refinement

What changed:
- Updated `vite.config.js` PWA manifest: set `theme_color` to `#0a0a0a` and `background_color` to `#000000` to match the design system.
- Added `purpose: 'any maskable'` to PWA SVG icons for better Android adaptive icon support.
- Refactored `ReloadPrompt.jsx` to use design system tokens (`bg-theme-surface`, `bg-theme-primary`) instead of hardcoded colors.
- Refined the 3-color palette (Black, Emerald, Gold) on the Quran page: Surah titles, hover states, and bookmarks now utilize `theme-accent` (Gold).
- Fixed Arabic text layout shifting issues caused by scaling effects during audio playback.
- Redesigned the karaoke active word highlight to a stable, solid emerald block cursor with white text for maximum readability and layout preservation.

Why:
- PWA manifest colors were still using an older slate-blue theme (`#0f172a`), creating a visual disconnect on mobile.
- The Quran reader UI was suffering from layout shifts when reading word-by-word due to aggressive CSS scaling. The new solid block cursor is cleaner, stable, and more legible.
- Exploiting the Gold accent color adds a premium, authentic "Mus'haf" aesthetic to the sacred text metadata.

Files affected:
- vite.config.js — Manifest colors and maskable icons.
- src/components/ReloadPrompt.jsx — Applied theme tokens.
- src/components/QuranReader.jsx — Refined Gold styling and Karaoke block cursor.

Breaking changes:
- None.

Notes for review:
- The karaoke (word-by-word highlight) is now extremely stable. Test the audio playback to see the solid green cursor tracking the text seamlessly.
