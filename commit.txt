[2026-08-02] — Fix: Prevent raw HTML attribute leaking in Tajweed rendering

What changed:
- Removed string splitting logic on `text_tajweed` HTML in `QuranReader.jsx`.
- Render intact Tajweed HTML using `dangerouslySetInnerHTML` for complete structural integrity without corrupting `<tajweed class=...>` tags into visible plain text.

Why:
- Splitting HTML strings by whitespace cut open custom `<tajweed class=...>` tags across words, leaking raw strings like `class=qalaqah>` as text. Keeping HTML intact resolves the bug completely.

Files affected:
- FRONTEND/islam app/src/components/QuranReader.jsx

Breaking changes:
- None.
