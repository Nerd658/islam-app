[2026-08-02] — Fix: Auto-scroll positioning relative to parent overflow container

What changed:
- Updated `useEffect` in `QuranReader.jsx` to locate the parent `.overflow-y-auto` container in `App.jsx` and calculate exact relative scroll offsets (`scrollTop + relativeTop - (containerHeight / 2)`).

Why:
- Standard `scrollIntoView()` on inner elements can fail inside nested flex layout containers (`overflow-y-auto`). Calculating the parent offset guarantees smooth centering on all browsers and devices.

Files affected:
- FRONTEND/islam app/src/components/QuranReader.jsx

Breaking changes:
- None.
