[2026-08-01] — Fix: handle missing country_code in Nominatim search results

What changed:
- Added a fallback check for `country_code` in `cleanLocationResults.js` before calling `.toUpperCase()`.

Why:
- The Nominatim API occasionally returns location results without a `country_code`, causing a `Cannot read properties of undefined (reading 'toUpperCase')` crash on the frontend when searching for certain locations.

Files affected:
- FRONTEND/islam app/src/utils/cleanLocationResults.js

Breaking changes:
- None.
