[2026-08-01] — Feature: Islamic Events Countdown (v2.1.0)

What changed:
- Added a new `Events.jsx` page to display upcoming major Islamic events (Ramadan, Aïd al-Fitr, Hajj/Arafat, Tabaski, etc.).
- Created a service `fetchEvents.js` that automatically calculates the number of days remaining. It queries the Aladhan API to get the current Hijri year and dynamically projects the future Gregorian dates for each event.
- Added a "Dates" tab in the bottom `Navigation.jsx` bar using the `CalendarDays` icon.

Why:
- Because the Hijri calendar is lunar, it shifts by ~11 days each year relative to the Gregorian calendar. Muslims constantly need to check "how many days left until Ramadan or Eid?". This feature automates that math elegantly.

Files affected:
- FRONTEND/islam app/src/api/fetchEvents.js (New)
- FRONTEND/islam app/src/pages/Events.jsx (New)
- FRONTEND/islam app/src/App.jsx (Updated Router)
- FRONTEND/islam app/src/components/Navigation.jsx (Added tab)

Breaking changes:
- None.

Notes for review:
- The dates are based on algorithmic moon calculations (Umm al-Qura or similar via Aladhan). A disclaimer is displayed to remind users that exact dates may vary by +/- 1 day depending on local moon sighting.
