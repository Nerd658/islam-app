[2026-08-02] — Refactor: Split Arabic learning into dedicated standalone page components

What changed:
- Created `src/pages/arabic/` directory containing 5 dedicated standalone sub-page components:
  1. `ArabicAlphabet.jsx` (`/arabic/alphabet`) — 28 letters, writing forms & audio.
  2. `ArabicVocabulary.jsx` (`/arabic/vocabulary`) — 80% Quranic vocabulary flashcards & audio.
  3. `ArabicTajweed.jsx` (`/arabic/tajweed`) — Tajweed rules reference & audio examples.
  4. `ArabicQuiz.jsx` (`/arabic/quiz`) — Interactive QCM quiz mode with score tracking.
  5. `ArabicGrammar.jsx` (`/arabic/grammar`) — Nahw grammar basics (Ism, Fi'l, Harf).
- Updated `App.jsx` to register `/arabic` sub-routes with `React.lazy()` code splitting.
- Updated `Navigation.jsx` to link sidebar sub-items directly to their dedicated routes.
- Removed monolithic `Arabic.jsx`.

Why:
- Improves code maintainability, reduces per-page bundle size, and establishes a clean modular architecture.
