[2026-08-01] — UI/UX: Switch Adhkar categories to a Dropdown menu

What changed:
- Removed the horizontal scroll chips for Adhkar categories.
- Implemented a sleek, custom dropdown menu (`select` alternative) using absolute positioning and `lucide-react` icons (ChevronDown).
- The dropdown adapts automatically to the number of categories and features a custom scrollbar if the list becomes too long.

Why:
- The user requested a "Pro" UI pattern instead of horizontal scrolling.
- A dropdown menu takes up less horizontal space and is a universally understood interaction pattern for filtering large datasets on both mobile and desktop.
