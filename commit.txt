[2026-08-02] — Feature: Add Tajweed letter coloring & Offline Surah Caching

What changed:
- Tajweed Letter Coloring: Integrated Tajweed Uthmani text API (`/api/v4/quran/verses/tajweed`) and added CSS coloring rules for Tajweed rules (Red for Madd, Green for Ghunna, Blue for Qalqala, Orange for Ikhfa, Purple for Idgham, Cyan for Iqlab).
- Added an interactive Tajweed toggle button and Tajweed legend guide inside `QuranReader.jsx`.
- Offline Surah Download: Added a "Télécharger / Hors-Ligne" button per Surah in `QuranReader.jsx` saving verses & audio map to `localStorage` for offline reading.
- PWA Workbox Caching: Configured `runtimeCaching` in `vite.config.js` with `CacheFirst` for Quran API and `NetworkFirst` for Aladhan API.

Why:
- Allows users to read and learn Tajweed pronunciation letter-by-letter with authentic color coding.
- Gives users full offline access to Quran surahs even without internet.
