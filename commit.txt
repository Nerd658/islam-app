[2026-08-01] — Major Refactor (v2.0.0): Security, Modularity, UI Navigation, and Tasbih

What changed:
- **Backend Architecture**: Fully restructured into `routes/`, `controllers/`, and `middlewares/`. Separated concerns for better maintainability.
- **Backend Security**: Added `helmet` for HTTP headers, `express-rate-limit` to prevent chatbot API abuse (cost control), and `zod` for rigorous input validation.
- **Frontend Architecture**: Integrated `react-router-dom` to transition from a single long scrollable page to a multi-page app (Home, Quran, Adhkar, Tasbih).
- **Navigation**: Created a sticky bottom navigation bar (`Navigation.jsx`) optimized for mobile using `lucide-react` icons.
- **New Feature - Tasbih**: Added a digital rosary page (`Tasbih.jsx`) with counting, reset, and haptic feedback to help users track their Dhikr (Subhanallah, Alhamdulillah, Allahu Akbar).

Why:
- The previous backend was a single file (`server.js`) making it hard to scale or test. 
- The Chatbot API is connected to OpenRouter (which can cost money or have limits); rate-limiting is essential for production.
- A multi-page frontend with a bottom tab bar significantly improves the User Experience on mobile devices, matching standard modern Islamic apps.
- The Tasbih is one of the most requested features for everyday Muslim users.

Breaking changes:
