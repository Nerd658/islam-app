[2026-08-02] — Fix: Strip raw Tajweed HTML tags when Tajweed mode is disabled

What changed:
- Updated `QuranReader.jsx` to strip HTML tags (`.replace(/<[^>]+>/g, '')`) whenever `tajweedMode` is toggled OFF (disabled).

Why:
- Fixes bug where disabling Tajweed rules caused raw unparsed HTML tags like `<tajweed class=madda_necessary>` to appear as plain text on screen.

Files affected:
- FRONTEND/islam app/src/components/QuranReader.jsx

Breaking changes:
- None.
