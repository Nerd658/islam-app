2026-08-07 — Refactor Adhkar UI to Premium Design System

What changed:
- Added PageHeader to Adhkar for consistency with Tasbih and Stories.
- Implemented a "Glassmorphism" effect for the filter dropdown to improve contrast against the dark background.
- Redesigned `DhikrCard` with `rounded-3xl` corners, soft drop-shadows, and a responsive layout.
- Added a "glow" and "gradient" effect when an Adhkar repetition is completed (isDone state).
- Added pagination (4 items per page) to the Adhkar list to optimize performance on mobile.
- Removed forced black background (`bg-theme-bg`) to inherit the natural dark theme surface.

Why:
- The Adhkar page lacked the premium feel introduced in Tasbih.
- Long lists of Adhkar caused rendering issues on mobile, which is solved by pagination.
- The filter dropdown was previously blending into the background, making it hard to see.

Files affected:
- FRONTEND/islam app/src/pages/Adhkar.jsx — UI layout, PageHeader, dropdown redesign.
- FRONTEND/islam app/src/components/AdhkarList.jsx — Pagination logic (4/page).
- FRONTEND/islam app/src/components/DhikrCard.jsx — Premium UI styling and completed states.

Breaking changes:
- None.
