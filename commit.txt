[2026-08-01] — Feature: Quran and Tafsir Reader Integration

What changed:
- Added a `QuranReader.jsx` component that fetches the 114 Surahs from the open `api.quran.com`.
- Created an interface to display Surahs in a grid, allowing the user to select one.
- Implemented fetching of Uthmani script verses for the selected Surah, with correct Arabic right-to-left layout and beautiful styling.
- Integrated the Quran reader into the main `App.jsx` view.

Why:
- Access to the Quran is the core of any Islamic application. Connecting to `api.quran.com` allows us to display authenticated verses without bloating the app's size.
- This satisfies the requirement of making the app as useful as possible to the Muslim community.
