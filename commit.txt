[2026-08-01] — UI/UX: Replace all emojis with sleek Lucide icons

What changed:
- Removed all text emojis (stickers) from `Home.jsx`, `QuranReader.jsx`, and `fetchEvents.js`.
- Replaced them with professional, minimalist SVG icons from `lucide-react` (e.g., `<MapPin>`, `<BookOpen>`, `<Moon>`, `<Gift>`).
- Adjusted container styling in `Events.jsx` to properly align the new SVG elements.

Why:
- Per user request, emojis feel less "pro" and can render inconsistently across different operating systems. Using `lucide-react` ensures a uniform, premium Vercel-like aesthetic.

Files affected:
- FRONTEND/islam app/src/pages/Home.jsx
- FRONTEND/islam app/src/components/QuranReader.jsx
- FRONTEND/islam app/src/api/fetchEvents.js
- FRONTEND/islam app/src/pages/Events.jsx
